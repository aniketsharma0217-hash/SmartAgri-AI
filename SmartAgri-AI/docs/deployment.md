# SmartAgri AI — Deployment Guide

This document covers all supported deployment targets for the SmartAgri AI application.

---

## 1. Prerequisites

Before deploying, ensure all model artifacts and data splits have been generated by running the complete training pipeline once:

```bash
# From project root with virtual environment activated
source .venv/bin/activate

# 1. Preprocess data
python -m src.preprocessing

# 2. Train all candidate models
python -m src.train

# 3. Evaluate and select final model
python -m src.evaluate
```

Verify the following artifacts exist before starting the application:

```
models/crop_recommender_model.joblib  (3.4 MB)
models/scaler.joblib
models/label_encoder.joblib
models/metadata.json
models/crop_profiles.json
```

## 2. Local Development Server

The simplest deployment — runs directly on your machine.

### Step 1 — Activate virtual environment

```bash
cd /path/to/SmartAgri-AI
source .venv/bin/activate         # macOS / Linux
# .venv\Scripts\activate          # Windows
```

### Step 2 — Launch application

```bash
streamlit run app/app.py
```

The terminal will display:
```
  You can now view your Streamlit app in your browser.
  Local URL: http://localhost:8501
  Network URL: http://<your-local-ip>:8501
```

### Step 3 — Open in browser

Navigate to `http://localhost:8501`.

### Stopping the server

Press `Ctrl+C` in the terminal.

## 3. Streamlit Community Cloud

Streamlit Community Cloud provides free hosting for public repositories.

> [!NOTE]
> The model artifact files (`models/*.joblib`) are binary files of ~3–4 MB. GitHub's file size limit is 100 MB per file, so these artifacts are within the allowed range. However, the dataset (`data/raw/Crop_recommendation.csv`) must either be committed to the repository or downloaded at startup.

### Steps

1. **Push to GitHub**: Push the entire project to a public GitHub repository.
2. **Sign in to Streamlit Cloud**: Go to https://share.streamlit.io and sign in with GitHub.
3. **Deploy a new app**:
   - Repository: `<your-username>/SmartAgri-AI`
   - Branch: `main`
   - Main file path: `app/app.py`
4. **Click Deploy**. Streamlit Cloud will install dependencies from `requirements.txt` automatically.

### Environment variables on Streamlit Cloud

If the dataset path or model path is non-standard, set them under **Settings → Secrets** in the Streamlit Cloud dashboard (TOML format):

```toml
SMARTAGRI_DATA_DIR = "/mount/src/<repo-name>/data"
SMARTAGRI_MODELS_DIR = "/mount/src/<repo-name>/models"
```

## 4. Docker Containerization

For reproducible, isolated deployment in containers.

### Dockerfile

Create a `Dockerfile` at the project root:

```dockerfile
FROM python:3.12-slim

WORKDIR /app

# Install dependencies
COPY requirements.txt .
RUN pip install --upgrade pip && pip install -r requirements.txt

# Copy source code and artifacts
COPY . .

# Expose Streamlit default port
EXPOSE 8501

# Streamlit configuration
ENV STREAMLIT_SERVER_HEADLESS=true
ENV STREAMLIT_SERVER_PORT=8501
ENV STREAMLIT_SERVER_ADDRESS=0.0.0.0
ENV MPLCONFIGDIR=/app/.cache/matplotlib

CMD ["python", "-m", "streamlit", "run", "app/app.py"]
```

### Build the image

```bash
docker build -t smartagri-ai:latest .
```

### Run the container

```bash
docker run -p 8501:8501 smartagri-ai:latest
```

Access at `http://localhost:8501`.

### Run with environment variable overrides

```bash
docker run -p 8501:8501 \
  -e SMARTAGRI_DATA_DIR=/app/data \
  -e SMARTAGRI_MODELS_DIR=/app/models \
  smartagri-ai:latest
```

## 5. Environment Variable Reference

All configurable paths are read from environment variables with safe defaults. No secrets or credentials are required.

| Variable | Default Value | Purpose |
| :--- | :--- | :--- |
| `SMARTAGRI_DATA_DIR` | `<project>/data` | Root directory for raw and processed data |
| `SMARTAGRI_MODELS_DIR` | `<project>/models` | Directory for serialized model artifacts |
| `SMARTAGRI_RAW_DATASET_PATH` | `<data>/raw/Crop_recommendation.csv` | Explicit CSV path override |
| `MPLCONFIGDIR` | `<project>/.cache/matplotlib` | Matplotlib font/glyph cache directory |

## 6. Production Checklist

Before deploying to a shared or production environment, verify:

- [ ] All 5 model artifacts exist: `crop_recommender_model.joblib`, `scaler.joblib`, `label_encoder.joblib`, `metadata.json`, `crop_profiles.json`
- [ ] Dataset file is present at `data/raw/Crop_recommendation.csv` or path is overridden via `SMARTAGRI_RAW_DATASET_PATH`
- [ ] `reports/model_comparison.json` exists (required for Model Insights page)
- [ ] `reports/figures/*.png` exist (required for Data Explorer page)
- [ ] Full test suite passes: `.venv/bin/pytest tests/ -q` → 74 passed
- [ ] No API keys, passwords, or secrets are committed to the repository
- [ ] `.gitignore` excludes `.venv/`, `__pycache__/`, `.env`, `.cache/`, `.pytest_cache/`

---

## 7. Known Deployment Constraints

1. **Model Re-training Required on Fresh Environment**: If deploying on a machine without pre-generated artifacts, the training pipeline (`src/preprocessing.py`, `src/train.py`, `src/evaluate.py`) must be run sequentially before the application starts.
2. **Matplotlib Cache**: In sandboxed or read-only filesystem environments, set `MPLCONFIGDIR` to a writable path. The application sets this automatically via `src/config.py` if running from the project root.
3. **Memory**: The Random Forest model (100 trees) requires approximately 50–100 MB of RAM at inference time. Most standard cloud deployment tiers (512 MB+) are sufficient.
